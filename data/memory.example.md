# Memory (rolling facts)

Timestamped bullets the assistant accumulates from chat. Soul holds stable identity; this holds **facts and preferences** that change over time.

The bot appends here after replies (and via `/remember`) when a small model pass finds durable items worth keeping.

Example entries:

- `[2026-05-01T12:00:00.000Z] User prefers hackathon reminders 24h before.`
- `[2026-05-02T08:00:00.000Z] Current focus: thesis deadline in June.`
